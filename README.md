# 🐍 Python - Data Structures & Recursion Exercises

Welcome to my Python practice repository! This project contains a collection of algorithmic exercises focused on **recursion** and **2D matrix manipulation**.

## 📂 Project Structure

Here is the list of the implemented exercises:

*   **01_somme_chiffres.py** : Recursive sum of the digits of an integer.
*   **02_count_digits.py** : Recursive count of the digits of an integer.
*   **03_zigzag_while.py** : 2D array traversal in a zigzag pattern (using `while` loops).
*   **04_zigzag_for.py** : 2D array traversal in a zigzag pattern (using `for` loops).
*   **05_somme_tableau.py** : Recursive calculation of the sum of an array's elements.
*   **06_zigzag_slicing.py** : Zigzag traversal using Python's slicing (`[::-1]`).
*   **07_palindrome.py** : Recursive function to check if a string is a palindrome.
*   **08_colonnes_recursives.py** : Recursive traversal of a matrix's columns (top-to-bottom and bottom-to-top).
*   **09_parcours_colonnes_zigzag.py** : Advanced recursive matrix traversal, combining row and column logic for complex zigzag patterns.

## 🚀 My Learning Journey (Personal Notes)

This repository is a milestone in my programming journey. While I had learned Python theory in class, this was my first time actively using it to solve complex algorithmic problems. 

**What I learned today:**

1. **The Power of the Debugger:** Using VS Code's debugger (`Step Into`, `Step Over`, and the Call Stack) completely changed my approach. Instead of guessing why a recursive function was failing, I could literally watch the variables change and the stack grow. Finding a bug by myself using the debugger was the best feeling of the day!
2. **The "Return" Trap:** I discovered the hard way that in recursion, if you call a function but forget the `return` keyword, Python evaluates it but throws away the result. A classic mistake, but a valuable lesson.
3. **The Magic of Slicing:** I finally understood how `[::-1]` works. It's not magic, it's just a negative step. Knowing this makes string and list manipulation so much easier.
4. **Thinking in 2D:** Combining recursion with 2D arrays (matrices) was challenging. Going from a simple line-by-line traversal to complex zigzag column patterns required a complete shift in my logic.

Python is a fascinating language. Moving from theory to practical, hands-on problem-solving is a challenge, but seeing the code finally execute perfectly after hours of debugging is totally worth it.
